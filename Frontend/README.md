# Construction Assistant Frontend

## Dev

From `E:\Projects\construction-assistant\Frontend`:

```bash
npm install
npm run dev
```

Открывай:
- `http://localhost:5173/`
- `http://127.0.0.1:5173/`

## Environment variables (optional)

Create `Frontend/.env`:

```env
VITE_AUTH_URL=http://localhost:5001
VITE_USER_URL=http://localhost:5002
VITE_PROJECT_URL=http://localhost:5003
```
